# DSTNS API Reference

This directory documents the full REST, SSE, and WebSocket API surface for DSTNS (v1.0.0).

- [Playback API](playback-api.md): Start, status, pause, resume, seek, stop, reset.
- [View API](view-api.md): Topology, dynamic state snapshots, static entity inspectors, logs.
- [Control API](control-api.md): Tick rate, module toggles, manual weather/traffic events, undo/redo.
- [News API](news-api.md): Real-time news event notifications.
- [System API](system-api.md): Health check, graceful process termination.
- [UI Overlay API](ui-overlay-api.md): Visual decision agent overlays.
- [Streaming](streaming.md): Server-Sent Events architecture.
- [Schemas](schemas.md): Data types and numeric formats.
- [Errors](errors.md): Error format and HTTP status codes.
- [Examples](examples.md): Curl snippets and workflow examples.
- [Lifecycle](lifecycle.md): State transition rules.
- [Versioning](versioning.md): Versioning policy.
- Machine-Readable OpenAPI 3.1 Spec: [`/api/openapi.yaml`](../../api/openapi.yaml).
