# API guide

The DSTNS server speaks JSON over HTTP under `/api/v1`. `GET /api/v1` returns
a machine-readable index of every route, generated by the server, so it cannot
drift from what is running.

## Who may do what

| Caller | Can |
|---|---|
| Anyone who can reach the port | Read every view; play, pause, seek, step, reset; change speed; use the control API; regenerate the world (unless disabled); terminate |
| The operator CLI (holds `logs/operator.token`) | Additionally start and prepare runs |
| A browser page on another origin | Read views only. Writes are refused with `CROSS_ORIGIN_FORBIDDEN` |

See [Security](../SECURITY.md).

## Quick examples

```bash
# What is running?
curl -s localhost:8090/api/v1/playback/status | jq '.data.lifecycle, .clock.simulated_current_time'

# Jump to the evening peak and hold there
curl -s -X POST localhost:8090/api/v1/playback/seek -d '{"target_time":"17:30:00"}'

# Close a road, then undo it
curl -s -X PUT localhost:8090/api/v1/control/edges/412 -d '{"closed":true}'
curl -s -X POST localhost:8090/api/v1/control/undo -d '{"count":1}'

# Start a run from a script (the CLI normally does this)
curl -s -X POST localhost:8090/api/v1/playback/start \
  -H "X-DSTNS-Operator: $(cat logs/operator.token)" -d '{"seed":"382923"}'

# Shut the server down
curl -s -X POST localhost:8090/api/v1/system/terminate
```
