# OpenAPI explorer

The DSTNS API described in [OpenAPI 3.1](https://spec.openapis.org/oas/v3.1.0),
rendered interactively below. Download the description:
[`openapi.yaml`](openapi.yaml).

!!! note "The server describes itself too"
    `GET /api/v1` returns the route index generated by the running server, which
    cannot drift from what is deployed. This description adds request and
    response schemas. Where the two disagree, the server is right; please
    [report it](https://github.com/varunkarthic/DSTNS/issues).

!!! tip "Trying requests"
    "Try it out" sends requests to `http://127.0.0.1:8090`, so it works when a
    server is running on this machine. Starting runs needs the operator
    credential (see [Security](../deployment/security.md#starting-runs-the-operator-credential)).
