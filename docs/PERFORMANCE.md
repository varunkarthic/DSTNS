# Performance & Scalability Benchmark

Measured performance metrics on local workstation:
- **Scenario Compilation**: 400 nodes, 1,520 edges compiled in ~26 ms.
- **A\* Strategic Routing**: ~5.7 $\mu$s per route calculation.
- **Snapshot Serialization**: ~2.1 ms per full dynamic snapshot across the entire network.
- **Memory Footprint**: < 25 MB RAM for 1,500-edge networks.
